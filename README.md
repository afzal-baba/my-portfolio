## Design System

**Color Palette**
- Background: `#EEF2FF` / `rgb(238, 242, 255)` - Soft lavender wash
- Primary Text / Heading: `#1E3A8A` / Blue-800 - "Afzal - Portfolio V2"
- Secondary Text: `#1F2937` - "DevOps Engineer | Mock Interview Prep"
- Card: `#FFFFFF` white with `0 4px 20px rgba(0,0,0,0.08)` shadow
- Card Radius: `12px-16px`

**Typography**
- Family: Inter / Segoe UI / Sans-serif
- Heading: 32px, Bold, Centered, Blue
- Subheading: 16px, Regular, Gray-800, Centered
- Card Title: 18px, Bold
- Card Body: 15px, Regular

**Layout**
- Single column, centered, max-width 600px
- 80px top padding
- 24px gap between header and card
- Card: 100% width on mobile, 400px on desktop, centered
- No navbar, no footer - pure minimal focus for V2

**Inspiration**
Clean DevOps dashboard style - same as Jenkins Blue Ocean / GitHub minimal cards. Built to load fast on Tomcat 10.
